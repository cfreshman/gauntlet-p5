# music-aipi web client

a minimalist web interface for the music-aipi system.

## features

- real-time chat interface with the ai assistant
- markdown rendering for rich responses
- clickable spotify links for discovered tracks
- responsive design for desktop and mobile
- terminal-inspired dark theme

## setup

1. install dependencies:
```
npm install
```

2. run development server:
```
npm run dev
```

3. build for production:
```
npm run build
```

4. preview production build:
```
npm run serve
```

## design

the web client features a minimalist visual design with:
- black background with white text
- monospace font (roboto mono)
- rounded buttons with accent color highlights
- compact interface with efficient use of space
- terminal-inspired aesthetic

## tech stack

- react
- vite
- socket.io-client
- react-markdown
- axios
